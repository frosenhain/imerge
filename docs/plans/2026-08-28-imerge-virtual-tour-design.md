# Imerge Corporate Center — Tour virtual

**Fecha:** 2026-08-28  
**Estado:** aprobado

## Objetivo

Incorporar el tour virtual 360° de Imerge como una experiencia inmersiva dentro del sitio.

## Experiencia

- Sección propia titulada **Recorré Imerge**, ubicada inmediatamente después de Espacios.
- Iframe de ancho completo con proporción panorámica para navegar el tour sin salir del sitio.
- Una barra superior breve explica el gesto de explorar y ofrece apertura en una pestaña/pantalla completa.
- El tour usa el enlace proporcionado por Life on Mars y conserva sus controles propios.

## Accesibilidad y comportamiento

- El iframe tiene título descriptivo.
- El enlace alternativo abre el tour en una nueva pestaña para quienes prefieran verlo expandido.
- No se reproduce contenido de manera automática.
