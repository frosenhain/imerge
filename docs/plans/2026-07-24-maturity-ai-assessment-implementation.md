# Plan de implementación del MVP

1. Inicializar la aplicación Next.js con TypeScript, Tailwind y dependencias de gráficos.
2. Definir tipos de assessment, datos de demostración y configuración de scoring.
3. Implementar funciones puras para métricas, segmentos, comparación y tensiones.
4. Construir el shell responsive, navegación, filtros globales y modos claro/oscuro.
5. Implementar las vistas de pulso general, radar, ranking y distribución por pregunta.
6. Implementar comparador de segmentos, brechas y explorador de preguntas.
7. Añadir asistente grounded local, actividades de clase y relato guardado en memoria.
8. Verificar tipos, lint, build y recorrido visual local.

## Criterio de terminación

La demo debe ser ejecutable localmente, presentar datos identificados como demostrativos, ocultar segmentos pequeños, trazar cada interpretación a métricas visibles y permitir alternar entre exploración libre y una secuencia guiada de clase.
